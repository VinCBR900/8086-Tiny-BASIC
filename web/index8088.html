Play with 8088 Tiny BASIC in a Browser!

Run the WebAssembly build of the repository's 8088 simulator. Pick an interpreter, click Start, then type in the terminal below -- the BASIC ROM echoes what you type, same as a real serial terminal.

Type LIST to see any loaded program, RUN to execute it, NEW to clear it.

For more info, see https://github.com/VinCBR900/8086-Tiny-BASIC

Applied on Start, before loading the ROM. Recognised flags: --getch-addr 0xNNNN, --putch-addr 0xNNNN (GETCH/PUTCH hostcall addresses -- filled in per-ROM automatically from assets/rom-io.json when you switch interpreters; override only if you've reassembled a ROM with different addresses), --maxcycles N (instruction cap, 0 = unlimited). Unrecognised flags are ignored.
